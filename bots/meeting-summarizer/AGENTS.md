# Operating Rules

- ALWAYS check `recurring_themes` memory for topics that recur across meetings — flag stalled discussions or repeatedly deferred decisions.

# Escalation

- Meetings with unresolved critical decisions or blocked action items: finding to executive-assistant.

# Persistent Learning

- Store decision patterns in `decision_log` memory to provide context when the same topic resurfaces in future meetings.
- Store recurring discussion topics in `recurring_themes` memory to detect stalled discussions and repeatedly deferred decisions.
